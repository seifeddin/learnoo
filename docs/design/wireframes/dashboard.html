Flow 5 — Dashboard with bookmarks, and role-based entry points

Wireframe, not production UI. The MVP has bookmarks but no progress tracking (IMPLEMENTATION_PLAN "Student benefit"), so there is no "continue where you left off", streak or percentage. Lesson titles in brackets are placeholders, not a chosen chapter.

Covers: student dashboard, empty bookmarks, unavailable bookmarked lesson, search with no results, Arabic interface, desktop, and the extra entries Teacher / Reviewer / Admin see.

5.1 Mobile — student

Annotations

  1. 1–2Same header as the reader. The menu holds browse, language switch, account and sign out.
  2. 3Title search, accent-insensitive. Results open a page (5.3); no type-ahead required for MVP.
  3. 4Bookmarks, newest first. Each row: one link (title) and one remove button whose accessible name includes the title. Removing shows "Signet retiré" with an "Annuler" action in a polite live region, and focus moves to the next row.
  4. 5Browse section → subject → chapter. The section filter defaults to the student's optional registration choice.

Unavailable bookmarks (unpublished or withdrawn) stay listed, without link, with a written state — never colour alone. The bookmark targets the stable lesson identity and comes back if the lesson is republished.

5.4 Arabic interface

  • Each French title is its own lang="fr" dir="ltr" element, so it aligns as a unit inside the RTL card; the remove button sits on the inline end (left).
  • Search input uses dir="auto" because students may type French or Arabic.
  • Unverified Arabic labels are placeholders pending native review.

5.6 Role-based entry points

The same dashboard shell gains entries only when the server reports the corresponding permission. Labels follow the confirmed account types; each entry is gated by the existing independent permission shown in brackets.

  • Items needing the teacher's action ("Modifications demandées") sort first.
  • Every status is written text; colour is supplementary.
  • Richer teacher dashboards are LRN-017 (M2); this is the minimum list needed for M1.
  • "Nouvelle leçon" asks for section/subject/chapter from the catalogue first. A teacher may write for any existing chapter; proposing new chapters is out of scope here.
